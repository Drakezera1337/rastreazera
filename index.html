      Configurações

      Sincronizar entre computador e celular

      Os rastreios ficam salvos neste navegador. Para ver a mesma lista em outros aparelhos, use um Gist secreto do GitHub como “nuvem”. Crie um token em github.com/settings/tokens com permissão só de gist, cole abaixo e salve. No outro aparelho, use o mesmo token e o mesmo ID do Gist.

      Usar no celular

      Com a sincronização ligada, mostre um QR code e aponte a câmera do celular: o site abre já configurado (mesmos pacotes, de qualquer lugar).

      Aponte para o QR code que aparece no PC em ⚙️ → Mostrar QR.

      O QR contém o seu token do GitHub: não compartilhe nem tire print dele. Some ao fechar.

      Onde buscar pedidos

      Vale para a busca automática (a cada 1 hora) e para o botão 🔄 Buscar pedidos. Desmarque um local para deixá-lo de fora.

      Importar pedidos (Shopee e AliExpress)

      Arraste o botão abaixo para a barra de favoritos. Depois, com a página de pedidos da Shopee ou do AliExpress aberta e logada, clique no favorito: os pedidos a caminho são cadastrados (ou atualizados) aqui automaticamente.
