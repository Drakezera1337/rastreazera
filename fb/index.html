FB Radar

Configurações

🔔 Notificações neste aparelho

O PC avisa cada anúncio novo das cidades escolhidas (precisa do PC ligado com o Chrome aberto).

📍 Cidades

Só entram anúncios destas cidades (uma por linha). Vazio = todas as que o Facebook mostrar.

📱 Configurar o celular

No celular, abra o FB Radar → ⚙️ → Ler QR do PC e aponte para este código (ou aponte a câmera do celular direto, para abrir já configurado).

🔗 Conectar ao PC

No PC, abra o FB Radar (localhost:5500/fb) → ⚙️ → Mostrar QR code.

🧩 Coletor (no PC)

A extensão FB Radar Coletor (pasta fb/coletor) roda no Chrome do PC, logado no Facebook, e confere a categoria Consoles de Video Game a cada poucos minutos. Ligue pelo ícone dela (▶ Iniciar).
